  Alternative:  .\test_webhook.ps1 or .\test_curl.bat

URLs:
  Application:  http://localhost:8000
  webhook.site: https://webhook.site/401957a8-71fe-4435-9776-8dfa554dbb5c
  API:          http://localhost:8000/api/webhooks

Files generated:
  .webhook_token - Your auth token (keep safe!)
  var/log/dev.log - Symfony logs for debugging

Endpoints (6 total):
  GET    /api/webhooks           - List all
  POST   /api/webhooks           - Create new
  GET    /api/webhooks/{id}      - Get one
  PUT    /api/webhooks/{id}      - Update
  DELETE /api/webhooks/{id}      - Delete
  POST   /api/webhooks/{id}/test - Send test
