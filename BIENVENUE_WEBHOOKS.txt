🎯 LE SYSTÈME FAIT MAINTENANT
═══════════════════════════════════════════════════════════════════════════════════

Quand un étudiant clique "Commencer Quiz":
  ↓
  1. Backend enregistre l'heure de début dans la BD
  2. Service génère un webhook 'quiz_started'
  3. Webhook est signé avec HMAC-SHA256 (sécurité)
  4. Webhook est envoyé à votre URL webhook.site
  5. webhook.site le reçoit et l'affiche
  ✅ Admin voit immédiatement que l'étudiant a commencé

Quand l'étudiant clique "Soumettre":
  ↓
  1. Backend calcule le score
  2. Service génère un webhook 'quiz_completed'
  3. Inclut le score, pourcentage, résultat (réussi/échoué)
  4. Webhook est signé et envoyé
  5. webhook.site le reçoit
  ✅ Admin voit immédiatement le résultat

🔐 SÉCURITÉ
═══════════════════════════════════════════════════════════════════════════════════

Chaque webhook est signé avec HMAC-SHA256:

Header: X-Webhook-Signature: sha256=abc123def456...

✅ Cela garantit que:
   1. Le webhook vient de VOTRE serveur (pas un attaquant)
   2. Le contenu n'a pas été modifié en transit
   3. C'est légitime et authentique

✅ Voir sur webhook.site:
   1. Cliquez sur une requête
   2. Allez dans "Headers"
   3. Trouvez: X-Webhook-Signature
   4. Vous voyez la signature HMAC

❌ "Token not found"
   → Lancez: php setup_webhook_admin.php

❌ "Connection refused on port 8000"
   → Port occupé: netstat -ano | findstr :8000
   → Kill: taskkill /PID <PID> /F

❌ "No webhooks on webhook.site"
   → Vérifiez Symfony en Terminal 2
   → Vérifiez le test en Terminal 3
   → Relancez le test

❌ "PowerShell execution error"
   → Lancez en admin
   → Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
