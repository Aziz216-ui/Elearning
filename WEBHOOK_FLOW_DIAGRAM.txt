STUDENT STARTS QUIZ:
────────────────────────────────────────────────────────────────────────────────

   Browser                            Your Server                    webhook.site
   ──────────────────────────────────  ─────────────────────────     ────────────────
   
   [Student clicks "Commencer Quiz"]   
   │                                   
   +──> GET /front/quiz/5/start        
   │    │                              
   │    │                              
   │    +──────────────────────────────> QuizController::start()
   │                                   │
   │                                   +─ Create QuizResult
   │                                   │  id: 123
   │                                   │  user: Student
   │                                   │  quiz: #5
   │                                   │  startedAt: NOW
   │                                   │  status: IN_PROGRESS
   │                                   │
   │                                   +─ Save to database
   │                                   │
   │                                   +─ Call QuizNotification
   │                                   │  Service::notifyQuizStarted()
   │                                   │
   │                                   +─ Find active webhooks
   │                                   │  for event: quiz_started
   │                                   │  → Found: 1 (webhook.site)
   │                                   │
   │                                   +─ Call WebhookDispatcher
   │                                   │  ::dispatch()
   │                                   │
   │                                   +─ Build payload
   │                                   │  {
   │                                   │    event: "quiz_started",
   │                                   │    timestamp: "2025-12-06...",
   │                                   │    data: {
   │                                   │      quiz_result_id: 123,
   │                                   │      student: {...},
   │                                   │      quiz: {...},
   │                                   │      course: {...},
   │                                   │      startedAt: "..."
   │                                   │    }
   │                                   │  }
   │                                   │
   │                                   +─ Sign with HMAC-SHA256
   │                                   │
   │                                   +─ POST to webhook.site
   │                                   │                           ──────> RECEIVE
   │    <──────────────────────────────+                           │
   │    Response: Quiz started!        │                           +─ Show in UI
   │                                   │
