🔄 FLUX COMPLET (VRAI SCÉNARIO)
═══════════════════════════════════════════════════════════════════════════════════

   1. Étudiant se connecte à http://localhost:8000/front/
   2. Étudiant accède au quiz
   3. Étudiant clique "Commencer Quiz"
      → Backend crée QuizResult avec startedAt
      → Service envoie webhook 'quiz_started' à webhook.site
      → Webhook.site reçoit la requête ✅

   4. Étudiant répond aux questions
   5. Étudiant clique "Soumettre"
      → Backend calcule le score
      → Service envoie webhook 'quiz_completed' à webhook.site
      → Webhook.site reçoit la requête ✅

   6. Admin regarde webhook.site
      → Voit que l'étudiant a commencé le quiz
      → Voit que l'étudiant a complété le quiz
      → Voit le score et les résultats
