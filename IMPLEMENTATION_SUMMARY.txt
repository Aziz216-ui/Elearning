━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Un système COMPLET et PRODUCTION-READY pour notifier les administrateurs en temps
réel lorsqu'un étudiant commence ou termine un quiz, via Webhooks HTTP.

 🎯 OBJECTIFS RÉALISÉS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ L'étudiant clique sur "Commencer Quiz"
   → Le backend crée une session QuizResult avec timestamp startedAt

✅ Le système enregistre dans la BD
   → Table quiz_result.started_at = NOW()

✅ Une notification est envoyée à l'admin
   → Via Webhook HTTP POST vers l'URL configurée

✅ L'admin voit instantanément
   → Dashboard en temps réel avec tous les événements
   → Détails: qui, quel quiz, heure exacte

✅ Le quiz continue normalement
   → L'étudiant n'est pas impacté
   → Ils peuvent terminer normalement

 🔐 SÉCURITÉ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ Signature HMAC-SHA256
   - Clé secrète unique par webhook
   - Envoyée en en-tête X-Webhook-Signature
   - Vérifiable par le récepteur

✅ Authentification
   - Rôle ROLE_ADMIN obligatoire
   - Vérification d'ownership (admins ne voient que leurs webhooks)

✅ Validation
   - Validation d'URL (filter_var FILTER_VALIDATE_URL)
   - Validation du type d'événement
   - JSON bien formé

✅ Robustesse
   - Retry automatique 3 fois
   - Délai entre les retries
   - Désactivation automatique après 10 échecs
   - Logging complet de chaque tentative

   $ php bin/console doctrine:migrations:migrate

2. ACCÉDER À L'ADMIN
   $ http://localhost:8000/admin/webhooks

3. CRÉER UN WEBHOOK
   - URL: https://webhook.site/unique-id
   - Type: quiz_started
   - Copier la clé secrète

4. TESTER
   - Cliquer le bouton 🧪 "Tester"
   - Ou faire passer un quiz à un étudiant

5. MONITORER
   - Voir le statut sur /admin/webhooks/status
   - Consulter les logs var/log/dev.log

Étudiant commence Quiz
    ↓
Frontend: Clique "Commencer"
    ↓
Backend QuizController.start()
    ↓
Crée QuizResult(startedAt = NOW)
    ↓
QuizNotificationService.notifyQuizStarted()
    ↓
Récupère les webhooks actifs
    ↓
WebhookDispatcher.dispatch()
    ↓
Pour chaque webhook:
  ├─ Signe le payload (HMAC-SHA256)
  ├─ POST vers l'URL du webhook
  ├─ Retry 3 fois si erreur
  ├─ Logs chaque tentative
  └─ Désactive après 10 échecs
    ↓
Admin reçoit la notification
    ↓
(Slack, Email, Dashboard, etc.)
