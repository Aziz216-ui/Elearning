   • Logging complet


🔐 SÉCURITÉ IMPLÉMENTÉE
════════════════════════════════════════════════════════════════════════════

✅ Signature HMAC-SHA256
   • Clé secrète unique par webhook (32 bytes)
   • Signature dans en-tête X-Webhook-Signature
   • Vérifiable par le récepteur

✅ Authentification
   • Rôle ROLE_ADMIN obligatoire
   • Vérification d'ownership (admins ne voient que leurs webhooks)

✅ Validation
   • Validation d'URL (filter_var)
   • Validation du type d'événement
   • JSON well-formed

✅ Fiabilité
   • Retry logic (3 tentatives + délai)
   • Graceful error handling
   • Désactivation intelligente après erreurs


📊 ÉVÉNEMENTS IMPLÉMENTÉS
═════════════════════════════════════════════════════════════════════════════

EVENT: quiz_started
   • Déclenché: Quand l'étudiant clique "Commencer Quiz"
   • Payload: Détails étudiant, quiz, cours, timestamp
   • Signature: Incluse et vérifiable

EVENT: quiz_completed
   • Déclenché: Quand l'étudiant soumet ses réponses
   • Payload: Idem + score, statut (réussi/échoué)
   • Signature: Incluse et vérifiable

🚀 DÉMARRAGE IMMÉDIAT
═════════════════════════════════════════════════════════════════════════════

1. Exécuter la migration:
   $ php bin/console doctrine:migrations:migrate

2. Accéder à l'admin:
   $ http://localhost:8000/admin/webhooks

3. Créer un webhook:
   • URL: https://webhook.site/unique-id
   • Type: quiz_started
   • Sauvegarder

4. Tester:
   • Cliquer 🧪 Tester
   • Ou faire passer un quiz

5. Monitorer:
   • Voir /admin/webhooks/status
   • Consulter var/log/dev.log
