1️⃣  Créer un webhook:

    curl -X POST http://localhost:8000/api/webhooks \
      -H "Content-Type: application/json" \
      -H "Authorization: Bearer YOUR_TOKEN" \
      -d '{
        "url": "https://webhook.site/unique-id",
        "eventType": "quiz_started"
      }'

2️⃣  Tester le webhook:

    curl -X POST http://localhost:8000/api/webhooks/1/test \
      -H "Authorization: Bearer YOUR_TOKEN"

3️⃣  Voir la notification sur webhook.site ✅

📊 ÉVÉNEMENTS WEBHOOK
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📌 quiz_started:
   → Envoyé quand un étudiant clique "Commencer Quiz"
   → Contient: Student, Quiz, Course, startedAt
   → Format: JSON + en-têtes custom

📌 quiz_completed:
   → Envoyé quand un étudiant soumet ses réponses
   → Contient: Student, Quiz, Score, Passed, Dates
   → Format: JSON + en-têtes custom

📌 all:
   → Souscrit aux deux événements

✅ Chaque webhook inclut:

   Header: X-Webhook-Signature
   Value:  sha256=<hmac-sha256-hash>
   
   → Vérifiez la signature côté serveur
   → Exemples Node.js, Python fournis
   → Utilisez ALWAYS des vérifications timing-safe

✅ Authentification API:

   Tous les endpoints requièrent:
   1. Bearer token valide
   2. ROLE_ADMIN sur l'utilisateur

🆘 DÉPANNAGE RAPIDE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ "Access Denied"
   ✓ Utilisateur doit avoir ROLE_ADMIN
   ✓ Vérifier: SELECT roles FROM user WHERE id = 1;

❌ "Webhook not found"
   ✓ Vérifier l'ID du webhook
   ✓ Vérifier: SELECT id FROM webhook_subscription;

❌ Webhook n'est pas envoyé
   ✓ is_active doit être 1
   ✓ URL doit être valide (HTTPS recommandé)
   ✓ Vérifier les logs: tail -f var/log/dev.log

❌ Échecs d'envoi répétés
   ✓ Après 10 échecs, webhook est désactivé automatiquement
   ✓ Réactiver: PUT /api/webhooks/1 avec "isActive": true
