═══════════════════════════════════════════════════════════════════════════════════
🔐 SÉCURITÉ - VÉRIFIER LA SIGNATURE HMAC
═══════════════════════════════════════════════════════════════════════════════════

   Chaque webhook inclut un header X-Webhook-Signature:

   1. Sur webhook.site, cliquez sur une requête
   2. Allez dans l'onglet "Raw"
   3. Trouvez le header: X-Webhook-Signature: sha256=...
   4. Vous pouvez le vérifier côté serveur avec le secret

   Format de signature:
   ─────────────────────────────────────────────────────────────
   X-Webhook-Signature: sha256=HASH

   Où HASH = HMAC-SHA256(json_payload, webhook_secret)

   Cela garantit que le webhook vient bien de votre serveur!

❓ DÉPANNAGE
═══════════════════════════════════════════════════════════════════════════════════

   ❌ "Token non trouvé"
      → Lancez: php setup_webhook_admin.php

   ❌ "Serveur Symfony non trouvé"
      → Lancez: php -S localhost:8000 -t public
      → Dans UN AUTRE terminal!

   ❌ "Authorization: Bearer token rejected"
      → Vérifiez que l'utilisateur a ROLE_ADMIN
      → Lancez: php setup_webhook_admin.php

   ❌ "Webhook not created"
      → Vérifiez l'URL webhook.site est valide
      → Vérifiez que curl/PowerShell peut accéder à http://localhost:8000

   ❌ "Aucune requête sur webhook.site"
      → Vérifiez que Symfony est lancé
      → Vérifiez que le webhook a été créé avec succès
      → Vérifiez que l'URL webhook.site est correcte
      → Vérifiez les logs Symfony: var/log/dev.log
