VUE D'ENSEMBLE DU FLUX
════════════════════════

1. ÉTUDIANT
   └─ Clique "Commencer Quiz"
   
2. BACKEND
   └─ QuizController.start()
      ├─ Crée QuizResult(startedAt = NOW)
      ├─ Appelle notifyQuizStarted()
      └─ Retourne la page du quiz
      
3. NOTIFICATION
   └─ QuizNotificationService
      ├─ Cherche les webhooks actifs
      └─ Pour chaque webhook:
         ├─ Appelle WebhookDispatcher.dispatch()
         ├─ Signe le payload (HMAC-SHA256)
         ├─ POST vers l'URL du webhook
         ├─ Retry 3 fois si erreur
         └─ Logs chaque tentative
         
4. ADMINISTRATION
   └─ Reçoit la notification
      ├─ Via Slack / Email / Dashboard / etc.
      └─ Peut voir les détails complets
      
5. QUIZ CONTINUE
   └─ L'étudiant n'est pas impacté
      ├─ Peut passer le quiz normalement
      └─ À la fin, déclenche quiz_completed
