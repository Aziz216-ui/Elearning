═══════════════════════════════════════════════════════════════════════════════════
❓ IF SOMETHING GOES WRONG
═══════════════════════════════════════════════════════════════════════════════════

Script error?
  → Make sure you're in the right directory
  → cd "c:\xampp\htdocs\version final\Elearning"
  → Try: .\test_webhook.ps1 (more detailed)

Port 8000 busy?
  → Kill it: netstat -ano | findstr :8000
  → Then: taskkill /PID <PID> /F
  → Retry: php -S localhost:8000 -t public

No webhooks on webhook.site?
  → Check that Symfony is running on Terminal 2
  → Check that the test ran on Terminal 3
  → Try the test again: .\quick_test_webhook.ps1
  → Check logs: tail var/log/dev.log

PowerShell execution error?
  → Run as Administrator
  → Then: Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
