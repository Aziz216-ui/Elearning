🔐 SECURITY - SIGNATURE VERIFICATION
═══════════════════════════════════════════════════════════════════════════════════

EVERY webhook includes an X-Webhook-Signature header:

Format:
  X-Webhook-Signature: sha256=<HASH>

What it is:
  - HASH = HMAC-SHA256 of the JSON body
  - Created with your webhook's unique secret
  - Proves the webhook came from YOUR server

How to verify (in your webhook receiver):

  1. Get the X-Webhook-Signature from the request header
  2. Use your webhook's secret to generate HMAC:
     hash = HMAC-SHA256(request_body_json, webhook_secret)
  3. Compare with the header signature
  4. If they match: ✅ Authentic
     If they don't: ❌ Reject (potential fraud)

Example in Node.js:
  const crypto = require('crypto');
  const signature = req.headers['x-webhook-signature'].replace('sha256=', '');
  const hash = crypto.createHmac('sha256', secret)
                      .update(JSON.stringify(req.body))
                      .digest('hex');
  if (crypto.timingSafeEqual(Buffer.from(signature), Buffer.from(hash))) {
    // Webhook is authentic!
  }

See examples:

  - examples/webhook-receiver-python.py

❌ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════════

❌ "Token not found"
   Solution: Run php setup_webhook_admin.php

❌ "Server not responding"
   Solution: Make sure to run php -S localhost:8000 -t public

❌ "Connection refused on port 8000"
   Solution: Port 8000 already in use
   → Find process: netstat -ano | findstr :8000
   → Kill process: taskkill /PID <PID> /F

❌ "Webhook not created - Authorization error"
   Solution: User doesn't have ROLE_ADMIN
   → Re-run: php setup_webhook_admin.php
   → Or check user roles: php bin/console doctrine:query:sql "SELECT id, roles FROM user"

❌ "No webhooks on webhook.site"
   Checklist:
   ├─ Symfony is running on http://localhost:8000
   ├─ Webhook was created (check with: .\quick_test_webhook.ps1)
   ├─ No firewall blocking outbound HTTPS
   ├─ URL is correct: https://webhook.site/401957a8-71fe-4435-9776-8dfa554dbb5c
   └─ Check Symfony logs: tail -f var/log/dev.log

❌ "Script execution policy error in PowerShell"
   Solution: Run PowerShell as Administrator
   Then: Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
   Then: .\quick_test_webhook.ps1

📊 WHAT GETS SENT
═══════════════════════════════════════════════════════════════════════════════════

QUIZ_STARTED Event:
──────────────────────────────────────────────────────────
  When: Student clicks "Commencer Quiz"
  Contains:
    ├─ event: "quiz_started"
    ├─ timestamp: ISO 8601 datetime
    ├─ data.student: ID, email, name
    ├─ data.quiz: ID, title, duration
    ├─ data.course: ID, title
    └─ data.startedAt: When quiz started

QUIZ_COMPLETED Event:
──────────────────────────────────────────────────────────
  When: Student clicks "Soumettre"
  Contains:
    ├─ event: "quiz_completed"
    ├─ timestamp: ISO 8601 datetime
    ├─ data.student: ID, email, name
    ├─ data.quiz: ID, title, duration
    ├─ data.course: ID, title
    ├─ data.score: Points earned
    ├─ data.maxScore: Total possible points
    ├─ data.percentage: Score percentage
    ├─ data.isPassed: True/False based on passing grade
    └─ data.completedAt: When quiz completed

🛠️ MANUAL API CALLS (IF SCRIPTS DON'T WORK)
═══════════════════════════════════════════════════════════════════════════════════

Get token first:
  cat .webhook_token
  (Outputs your token, copy it)

Then use TOKEN below:

1. LIST WEBHOOKS
   curl -X GET http://localhost:8000/api/webhooks \
     -H "Authorization: Bearer TOKEN"

2. CREATE WEBHOOK
   curl -X POST http://localhost:8000/api/webhooks \
     -H "Content-Type: application/json" \
     -H "Authorization: Bearer TOKEN" \
     -d '{"url":"https://webhook.site/401957a8-71fe-4435-9776-8dfa554dbb5c","eventType":"all"}'

3. TEST WEBHOOK
   curl -X POST http://localhost:8000/api/webhooks/1/test \
     -H "Authorization: Bearer TOKEN"

4. UPDATE WEBHOOK
   curl -X PUT http://localhost:8000/api/webhooks/1 \
     -H "Content-Type: application/json" \
     -H "Authorization: Bearer TOKEN" \
     -d '{"eventType":"quiz_started"}'

5. DELETE WEBHOOK
   curl -X DELETE http://localhost:8000/api/webhooks/1 \
     -H "Authorization: Bearer TOKEN"
