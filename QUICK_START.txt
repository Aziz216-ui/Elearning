⏱️  TEMPS: ~10 minutes pour une implémentation complète


ÉTAPE 1: MIGRATION (2 minutes)
══════════════════════════════

$ cd c:\xampp\htdocs\version\ final\Elearning

$ php bin/console doctrine:migrations:migrate

✅ Crée la table webhook_subscription
✅ Ajoute la colonne started_at à quiz_result


ÉTAPE 2: VÉRIFIER (1 minute)
════════════════════════════

$ php bin/console doctrine:query:sql "SELECT * FROM webhook_subscription LIMIT 1;"

✅ Devrait afficher une table vide (c'est normal)


ÉTAPE 3: ACCÉDER À L'INTERFACE ADMIN (1 minute)
════════════════════════════════════════════════

1. Ouvrir: http://localhost:8000/admin/webhooks
2. Se connecter avec un compte ADMIN
3. Cliquer "Créer un nouveau webhook"


ÉTAPE 4: CRÉER UN WEBHOOK DE TEST (2 minutes)
════════════════════════════════════════════════

A. Obtenir une URL de test:
   1. Aller à https://webhook.site
   2. Copier l'URL générée (ex: https://webhook.site/abc123)

B. Créer le webhook dans Elearning:
   1. Allez à /admin/webhooks
   2. Cliquez "Créer un nouveau webhook"
   3. Entrez:
      • URL: [collez l'URL de webhook.site]
      • Type d'événement: quiz_started
   4. Cliquez "Créer le webhook"
   5. 📋 COPIER LA CLÉ SECRÈTE (affichée)


ÉTAPE 5: TESTER (2 minutes)
═════════════════════════════

Option A: Via l'interface (recommandé)
   1. Allez à /admin/webhooks
   2. Vous voyez votre webhook dans la liste
   3. Cliquez le bouton 🧪 "Tester"
   4. Un événement test est envoyé

Option B: Via CLI
   $ php bin/console webhook:test 1
   (où 1 est l'ID du webhook)

Option C: Via un vrai quiz
   1. Connectez-vous comme étudiant
   2. Allez à un cours
   3. Cliquez "Commencer Quiz"
   ✅ L'événement est déclenché


ÉTAPE 6: VÉRIFIER LE RÉSULTAT (1 minute)
═════════════════════════════════════════

1. Allez sur votre URL webhook.site
2. Vous devriez voir la requête POST reçue
3. Consultez le payload JSON

Exemple de payload reçu:
{
  "event": "quiz_started",
  "timestamp": "2024-12-06T19:00:00+00:00",
  "data": {
    "quiz_result_id": 123,
    "student": {
      "id": 45,
      "email": "student@example.com",
      "fullName": "John Doe"
    },
    "quiz": {
      "title": "Mathematics Quiz",
      "totalPoints": 100
    },
    ...
  }
}


ÉTAPE 7: MONITORER (Optionnel)
═════════════════════════════════

Voir le statut détaillé:
   http://localhost:8000/admin/webhooks/status

Voir les logs:
   tail -f var/log/dev.log | grep -i webhook

📚 ÉTAPE SUIVANTE: INTÉGRATION
════════════════════════════════

Pour intégrer avec votre système:

1. Consulter les exemples:
   • examples/webhook_receiver_example.php (PHP)
   • examples/webhook_receiver_nodejs.js (Node.js)
   • examples/webhook_receiver_python.py (Python)

2. Adapter le code à votre système
   • Vérifier la signature HMAC
   • Traiter le payload
   • Faire l'action (email, Slack, etc.)

3. Déployer votre récepteur
   • Sur un serveur accessible (pas localhost)
   • Avec SSL/TLS (https://)

4. Configurer l'URL dans Elearning
   • /admin/webhooks -> URL de votre récepteur
   • Type d'événement que vous voulez
   • Tester!

❓ FAQ RAPIDE
═════════════

Q: Le webhook ne s'envoie pas?
R: Vérifier que le webhook est Actif, l'URL est valide

Q: La signature ne correspond pas?
R: Utiliser la clé secrète exacte du webhook

Q: Erreur "webhook_subscription table doesn't exist"?
R: Exécuter: php bin/console doctrine:migrations:migrate

Q: Comment vérifier les logs?
R: tail -f var/log/dev.log | grep webhook

Q: Puis-je avoir plusieurs webhooks?
R: Oui! Créez autant que vous voulez

Q: Peut-on envoyer à plusieurs URLs?
R: Oui! Créez un webhook par URL
