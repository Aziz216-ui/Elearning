🔌 ENDPOINTS API DISPONIBLES
═══════════════════════════════════════════════════════════════════════════════════

   1. GET    /api/webhooks                   → Lister tous les webhooks
   2. POST   /api/webhooks                   → Créer un webhook
   3. GET    /api/webhooks/{id}              → Consulter un webhook
   4. PUT    /api/webhooks/{id}              → Mettre à jour un webhook
   5. DELETE /api/webhooks/{id}              → Supprimer un webhook
   6. POST   /api/webhooks/{id}/test         → Tester l'envoi

   Authentification: Bearer Token + ROLE_ADMIN

📨 ÉVÉNEMENTS WEBHOOK
═══════════════════════════════════════════════════════════════════════════════════

   ┌─────────────────────────────────────────────────┐
   │ EVENT: quiz_started                             │
   ├─────────────────────────────────────────────────┤
   │ Triggered:  Student clicks "Commencer Quiz"    │
   │ Contains:   Student info, Quiz info, Time       │
   │ Payload:    ~500 bytes JSON                    │
   │ Signature:  HMAC-SHA256                        │
   └─────────────────────────────────────────────────┘

   ┌─────────────────────────────────────────────────┐
   │ EVENT: quiz_completed                           │
   ├─────────────────────────────────────────────────┤
   │ Triggered:  Student submits answers            │
   │ Contains:   Student info, Score, Pass/Fail      │
   │ Payload:    ~600 bytes JSON                    │
   │ Signature:  HMAC-SHA256                        │
   └─────────────────────────────────────────────────┘

   ┌─────────────────────────────────────────────────┐
   │ EVENT: all                                      │
   ├─────────────────────────────────────────────────┤
   │ Subscribed:  To both quiz_started and          │
   │              quiz_completed                    │
   │ Use case:    Dashboard updates, logging, etc.  │
   └─────────────────────────────────────────────────┘

🔐 SÉCURITÉ IMPLÉMENTÉE
═══════════════════════════════════════════════════════════════════════════════════

   ✅ HMAC-SHA256 Signature
      └─ Chaque webhook signé avec secret unique
      └─ En-tête: X-Webhook-Signature
      └─ Format: sha256=<hash>
      └─ Vérifiable côté serveur

   ✅ Authorization Required
      └─ Bearer Token validation
      └─ ROLE_ADMIN vérification
      └─ User ownership check

   ✅ Input Validation
      └─ URL validation
      └─ Event type validation
      └─ JSON payload validation

   ✅ Error Handling
      └─ Graceful failure handling
      └─ Automatic retry (up to 3x)
      └─ Failure tracking
